# @tailor-cms/ce-file-manifest

## 3.0.0

### Major Changes

- Migrate to CEK 2.3.1. Packages are now ESM-only: CommonJS builds and the `main` / `require` entry points are removed, and the manifest and server packages emit `index.js` / `index.d.ts` instead of `index.mjs` / `index.d.mts`. The top toolbar is removed; file upload, URL import, replace and remove now happen in the element body through the `TailorFileInput` dropzone. Files imported from a URL keep the entered title (or the URL's file name) as their download name instead of losing it, and removing a file clears its name.
